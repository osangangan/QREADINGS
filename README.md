# QREADINGS

QREADINGS is an ongoing research project dedicated to reconstructing the conceptual organisation of Qur'anic discourse prior to translation.

## Repository Structure

- SPECIFICATION
- CONCEPTUAL_LIBRARY
- CASE_STUDIES
- RESEARCH_LOG
- ALGORITHMS
- DATA
- REFERENCES

This repository is organised around methodology rather than translation.

The Specification defines the analytical process.

The Conceptual Library records current investigations.

Case Studies demonstrate the methodology.

The Research Log records ongoing investigations and discarded hypotheses.

No document in this repository possesses authority over the Qur'anic text.

All reconstructions remain provisional.
